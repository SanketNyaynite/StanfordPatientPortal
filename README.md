# CarePoint — Stanford Clinical Systems Analyst Assessment

An ASP.NET Core 8 + C# + EF Core + SQLite patient-search demo with a responsive HTML/CSS/JavaScript interface and REST API.

## Run in Visual Studio 2022
1. Extract the ZIP.
2. Open `StanfordPatientPortal.csproj` in Visual Studio 2022.
3. Select the project as startup project.
4. Sign in with the demo credentials below.

## Demo sign-in
- Email: `user@stanford.com`
- Password: `Stanford@2026`

## Features implemented
- Login/logout
- Search by MRN, first name, last name or date of birth
- Patient demographics, allergies, alerts, medications and document list
- Print patient demographics, allergies, alerts and medications
